② 採用するコマ

クリックで切り替え、Shift+クリックで範囲をまとめて切り替えます。

③ 再生の速さ（1コマを何ミリ秒表示するか）

1000ms = 1秒です。数字が大きいほど1コマが長く表示され、ゆっくりした動きになります。

最後のコマの長さ（通常は変更不要）
空欄なら、その直前のコマと同じ間隔になります。ループ再生の最後だけ長く止めたいときに使います。

表示時間を一括設定

選択中の 0 コマの表示時間を同じ値にそろえます（元に戻せます）。
